# 🌯 Amaka Shawarma Agent - AI Agent (Graph 9)

> An intelligent AI agent for automating shawarma orders and customer interaction.

### 🚀 Built With
- **LangGraph** - For agent workflow
- **Python** - Core logic
- **LangGraph API**

### ✨ What It Does
This agent handles:
- Takes customer shawarma orders automatically
- Understands customer preferences (chicken, beef, spicy, etc.)
- Manages order flow from start to finish
- Provides smart recommendations

This is **Graph 9** of my ACL Agent Development journey.

- `module1/` & `src/acl/` - Agent logic
